# Система автоматизованого формування тест-кейсів

## Опис проєкту

Вебзастосунок для автоматичного створення тест-кейсів
на основі вимог до програмного продукту.

## Основні можливості

- Введення опису функціональності.
- Автоматичне формування тест-кейсів.
- Редагування та видалення тестів.
- Збереження та пошук тест-кейсів.
- Експорт тестової документації.

## Користувачі

- Тестувальник
- QA-менеджер
- Розробник
- Адміністратор
